The essential notes

Beginner friendly
Eigenvalues & eigenvectors

A special direction

Av = λv,   v ≠ 0

For a square matrix A, a nonzero vector v is an eigenvector if multiplying it by A only scales it. The scale factor λ is its eigenvalue.

If λ > 0, the direction is preserved; if λ < 0, it is reversed. If λ = 0, the vector is mapped to zero. The zero vector itself is never an eigenvector.

Characteristic equation

Find the eigenvalues

det(A − λI) = 0

Subtract λ from each diagonal entry, take the determinant, and solve the resulting equation. Here I is the identity matrix.

A =
ab
cd
   ⇒   (a − λ)(d − λ) − bc = 0

For a 2 × 2 matrix, this becomes λ² − (a + d)λ + (ad − bc) = 0.

Eigenvector equation

Find the vectors

(A − λI)v = 0

Substitute one eigenvalue at a time. Write v = (x, y)ᵀ or (x, y, z)ᵀ, solve the simultaneous equations, and choose a nonzero solution.

Any nonzero multiple of an eigenvector is another eigenvector for the same eigenvalue. An eigenspace also includes zero, although zero is not an eigenvector.

Diagonalization

Change the basis

P⁻¹AP = D   ⇔   A = PDP⁻¹

Put linearly independent eigenvectors into the columns of P. Put their eigenvalues on the diagonal of D in exactly the same order. P is the change-of-basis matrix (also called the modal matrix).

An n × n matrix is diagonalizable over the chosen number system exactly when it has n linearly independent eigenvectors in that system.

Useful checks and common mistakes

FactWhat to remember
TraceThe sum of the eigenvalues equals the sum of the diagonal entries.
DeterminantThe product of the eigenvalues equals det A. Count repeated eigenvalues with multiplicity.
Triangular matrixIts eigenvalues are its diagonal entries.
Distinct eigenvaluesn distinct eigenvalues guarantee diagonalizability over a field containing them.
Repeated eigenvaluesCheck how many independent eigenvectors you can find; repetition alone does not decide diagonalizability.
Real symmetric matrixIt has an orthonormal eigenbasis. Choose an orthonormal eigenbasis as the columns of Q; then Q⁻¹ = Qᵀ.
Quick verificationCheck AP = PD. This avoids computing P⁻¹ just to verify the result.
Matrix powersIf A = PDP⁻¹, then Aᵏ = PDᵏP⁻¹ for positive integers k.
Order mattersColumn j of P must match diagonal entry j of D. Never place the eigenvectors as rows.

A real matrix can have complex eigenvalues. It may be diagonalizable over ℂ even when it is not diagonalizable over ℝ.
