2.1

Basic matrix algebra

Operations, direct sum, Kronecker product, transpose, conjugates, trace and determinant

Dimensions & operations

Start with rows and columns

An m × n matrix has m rows and n columns. Two matrices can be added or subtracted only when their orders agree. Multiply a matrix by a scalar by multiplying every entry.

(A + B)ᵢⱼ = aᵢⱼ + bᵢⱼ   (cA)ᵢⱼ = caᵢⱼ

If A is m × n and B is n × p, their ordinary product AB is m × p. Use row × column: (AB)ᵢⱼ = Σₖ aᵢₖbₖⱼ. Usually AB ≠ BA. The identity I satisfies AI = IA = A whenever the products are defined.

Direct sum

Place the matrices in separate blocks

A ⊕ B =
A0
0B

For A of order m × n and B of order p × q, the direct sum has order (m + p) × (n + q). The off-diagonal blocks are zero matrices of the required sizes.

For square matrices, tr(A ⊕ B) = tr A + tr B and det(A ⊕ B) = (det A)(det B). The eigenvalues form the combined lists of eigenvalues of A and B.

Direct product = Kronecker product

Replace every entry of A by a block

A ⊗ B =
a₁₁Ba₁₂B
a₂₁Ba₂₂B

Here direct product means the Kronecker (tensor) product, not ordinary matrix multiplication. If A is m × n and B is p × q, then A ⊗ B is mp × nq.

In general A ⊗ B ≠ B ⊗ A. For compatible dimensions, (A ⊗ B)(C ⊗ D) = AC ⊗ BD. For square A and B, the eigenvalues are all products λᵢμⱼ.

Transpose & conjugates

Three different operations

(Aᵀ)ᵢⱼ = aⱼᵢ   (A̅)ᵢⱼ = a̅ᵢⱼ
A† = (A̅)ᵀ,   (A†)ᵢⱼ = a̅ⱼᵢ

Transpose Aᵀ: interchange rows and columns. Complex conjugate A̅: replace i by −i in every entry. Conjugate transpose A†: perform both operations; it is also called the Hermitian adjoint.

(AB)ᵀ = BᵀAᵀ and (AB)† = B†A†: both reverse the order. Also (A†)† = A. Some books use A* for the adjoint; this page uses † to avoid ambiguity.

Trace

Add the diagonal entries

tr A = a₁₁ + a₂₂ + ⋯ + aₙₙ

Trace is defined here for square matrices. It is linear: tr(A + B) = tr A + tr B and tr(cA) = c tr A. Also tr(Aᵀ) = tr A and tr(A†) = (tr A)̅.

For square matrices of the same order, tr(AB) = tr(BA), even when AB ≠ BA. More generally, trace is unchanged by cyclic rotations of a product: tr(ABC) = tr(BCA) = tr(CAB). It is not generally unchanged by an arbitrary reordering.

Determinant

Use minors and cofactors

det
ab
cd

A minor Mᵢⱼ is the determinant left after deleting row i and column j. The cofactor is Cᵢⱼ = (−1)ⁱ⁺ʲ Mᵢⱼ. Expand along any row i:

det A = Σⱼ aᵢⱼCᵢⱼ = Σⱼ (−1)ⁱ⁺ʲ aᵢⱼMᵢⱼ

This is a recursive rule: compute an n × n determinant from (n − 1) × (n − 1) determinants, stopping at 1 × 1. In a first-row expansion the signs alternate +, −, +, −, … .

2.2

Inverse, rank & linear equations

Inverse methods, row reduction, rank and consistency of simultaneous equations

Inverse

Undo the matrix multiplication

AA⁻¹ = A⁻¹A = I

A square matrix is invertible exactly when det A ≠ 0. A matrix with det A = 0 is singular and has no ordinary inverse.

ab
cd
⁻¹ = 1ad − bc
d−b
−ca

This 2 × 2 formula requires ad − bc ≠ 0. For a diagonal matrix with nonzero entries, invert each diagonal entry.

Methods & identities

Find an inverse systematically

Adjugate method: compute the cofactor matrix, transpose it to get adj A, then A⁻¹ = (adj A)/(det A).

Gauss–Jordan method: form the augmented matrix [A | I] and row-reduce the left block to I. The right block becomes A⁻¹. If the left block cannot become I, A is singular.

(AB)⁻¹ = B⁻¹A⁻¹   (A⁻¹)ᵀ = (Aᵀ)⁻¹

For invertible A: det(A⁻¹) = 1/det A and (A⁻¹)⁻¹ = A. Do not invert a product without reversing the order.

Rank & nullity

Count the independent rows or columns

The rank is the number of linearly independent rows, equal to the number of independent columns. Row-reduce to echelon form and count pivots, or nonzero rows. Row operations do not change rank.

0 ≤ rank A ≤ min(m, n)

For A with n columns, rank A + nullity A = n. Nullity is the dimension of the solution space of Ax = 0, equal to the number of free variables. A square n × n matrix is invertible exactly when its rank is n.

Equivalently, rank is the largest order of a nonzero minor. A zero matrix has rank 0.

Simultaneous linear equations

Compare the coefficient and augmented ranks

Ax = b   [A | b]

Write the coefficients in A, the unknowns in x and the right-hand sides in b. Use elimination on the augmented matrix. Let r = rank A, r′ = rank[A | b], and n be the number of unknowns.

r ≠ r′: no solution. r = r′ = n: one unique solution. r = r′ < n: infinitely many solutions over ℝ or ℂ, with n − r free variables.

For a square invertible A, x = A⁻¹b. Cramer’s rule gives xⱼ = det Aⱼ / det A, where Aⱼ replaces column j of A by b.

Homogeneous equations

Ax = 0 always has the zero solution. It also has a nonzero solution exactly when rank A < n, where n is the number of unknowns. For square A, this is equivalent to det A = 0. A row such as [0 0 0 | 1] in an augmented matrix means 0 = 1 and proves inconsistency.

Two decompositions

Separate symmetry from antisymmetry

A = S + K   S = (A + Aᵀ)/2   K = (A − Aᵀ)/2

Every square real matrix has a symmetric part S and an antisymmetric part K. Check Sᵀ = S and Kᵀ = −K.

A = H + L   H = (A + A†)/2   L = (A − A†)/2

Every square complex matrix has a Hermitian part H and an anti-Hermitian part L. Also L/i is Hermitian, so one can write A = H + iG with H and G Hermitian.

Relations & useful properties

Recognize overlapping classes

Every real symmetric matrix is Hermitian. Every real antisymmetric matrix is anti-Hermitian. A real unitary matrix is orthogonal. A diagonal complex matrix is always normal, but it is Hermitian only when its entries are real.

Hermitian, anti-Hermitian and unitary matrices are all normal. A normal matrix need not belong to any of these three narrower classes.

Orthogonal and unitary matrices preserve lengths and inner products. For real orthogonal Q, det Q = ±1. For unitary U, |det U| = 1. For an odd-order antisymmetric matrix over ℝ or ℂ, det A = 0.

2.4

Eigenvalues & common eigenvectors

Spectral properties of normal, Hermitian, anti-Hermitian, unitary and general matrices; simultaneous eigenvectors

Eigenpair definition

Find the special nonzero vectors

Av = λv,   v ≠ 0

An eigenvector is a nonzero vector that is only scaled by A; λ is the eigenvalue. The zero vector is never an eigenvector. Any nonzero scalar multiple of an eigenvector has the same eigenvalue.

An eigenspace contains all eigenvectors for one eigenvalue together with zero. Its dimension is called the geometric multiplicity. The number of repetitions of a root of the characteristic polynomial is its algebraic multiplicity. Always 1 ≤ geometric multiplicity ≤ algebraic multiplicity.

Inner product & normal matrices

Use conjugation for complex vectors

⟨u, v⟩ = u†v   ‖v‖² = v†v

For a complex vector, use conjugate transpose in the inner product. Orthogonal vectors satisfy u†v = 0; a normalized vector has v†v = 1.

Spectral theorem: a complex square matrix is normal if and only if it can be diagonalized by a unitary matrix. Eigenvectors of a normal matrix belonging to distinct eigenvalues are orthogonal. Within a repeated eigenspace, choose an orthonormal basis.

Hermitian & anti-Hermitian spectra

Reality and imaginary eigenvalues

For H† = H, every eigenvalue is real. If Hv = λv, then v†Hv = λv†v is real, so λ is real. Eigenvectors with distinct eigenvalues are orthogonal.

For K† = −K, eigenvalues are purely imaginary or zero: λ̅ = −λ. One can write λ = iα with α real. If H is Hermitian, iH is anti-Hermitian and its eigenvalues are i times those of H, with the same eigenvectors.

Unitary & general spectra

Know what is and is not guaranteed

For U†U = I and Uv = λv, preservation of length gives ‖Uv‖² = |λ|²‖v‖² = ‖v‖². Therefore |λ| = 1. Unitary eigenvalues lie on the unit circle; they need not be real.

An arbitrary n × n complex matrix has n characteristic roots counted with algebraic multiplicity, but may have fewer than n independent eigenvectors. Distinct eigenvalues give independent eigenvectors. A real matrix can have complex eigenvalues, occurring in conjugate pairs.

The sum and product of all eigenvalues equal tr A and det A, respectively, with algebraic multiplicity counted.

Simultaneous eigenvectors

Diagonalize compatible matrices together

A common eigenvector v obeys Av = λv and Bv = μv. A common eigenbasis means n independent vectors that are eigenvectors of both matrices.

Two commuting Hermitian matrices have a common orthonormal eigenbasis. More generally, two complex normal matrices are simultaneously unitarily diagonalizable if and only if AB = BA. If A and B are diagonalizable over the same field, commuting is equivalent to having a common eigenbasis over that field.

Commuting arbitrary matrices need not have a complete common eigenbasis: a defective matrix and I already give a counterexample. Sharing just one eigenvector does not imply that the matrices commute.

Degeneracy

Resolve the freedom inside an eigenspace

If Av = λv and AB = BA, then A(Bv) = B(Av) = λBv. Thus B maps the λ-eigenspace of A into itself.

When that eigenspace is one-dimensional, Bv must be proportional to v. When it is degenerate, an arbitrary eigenvector of A need not be an eigenvector of B. Diagonalize B within that eigenspace to choose common eigenvectors. Worked example 18 shows the steps.

2.5

Basis changes & diagonalization

Computing eigenpairs, similarity transformations, change of basis and diagonalization

Calculate eigenvalues

Solve the characteristic equation

det(A − λI) = 0

Subtract λ from every diagonal entry, calculate the determinant, factor the polynomial and solve for its roots. The equation det(λI − A) = 0 gives the same roots.

A =
ab
cd
 ⇒ λ² − (a + d)λ + (ad − bc) = 0

For a triangular matrix, the eigenvalues are its diagonal entries. For a 3 × 3 matrix, expand along a row or column with many zeros whenever possible.

Calculate eigenvectors

Solve a homogeneous system for each root

(A − λI)v = 0

Substitute one eigenvalue at a time, row-reduce, identify the free variables and choose nonzero solutions. For a repeated eigenvalue, find a basis for the entire eigenspace; do not choose two multiples of one vector and count them as independent.

Check every proposed vector directly using Av = λv. If desired, divide it by its length to normalize it.

Change of basis

Distinguish a vector from its coordinates

Let the columns of an invertible matrix P be the new basis vectors expressed in the old basis. Then:

[x]old = P[x]new   [x]new = P⁻¹[x]old
Anew = P⁻¹AoldP

The vector or linear transformation stays the same; its coordinates or matrix entries change. The direction of P in these formulas depends on this explicit column convention.

Similarity & diagonalization

Choose an eigenvector basis

P⁻¹AP = D   ⇔   AP = PD   ⇔   A = PDP⁻¹

Similar matrices have the same characteristic polynomial, eigenvalues, trace, determinant and rank. They need not have the same entries or eigenvectors in a fixed coordinate basis.

For diagonalization, put n independent eigenvectors in the columns of P. Put their matching eigenvalues on the diagonal of D, in the same order. Diagonalization is possible exactly when a full eigenbasis exists over the chosen field.

A real matrix with non-real eigenvalues cannot be diagonalized to a real diagonal matrix using a real P. It can still be diagonalizable over ℂ.

A reliable diagonalization checklist

  1. Find the roots of det(A − λI) = 0.
  2. Find an eigenspace basis for every distinct root.
  3. Check that there are n independent eigenvectors in total.
  4. Build P from these columns and D from the matching eigenvalues.
  5. Check det P ≠ 0 and verify AP = PD or P⁻¹AP = D.

For a real symmetric matrix, choose orthonormal eigenvectors and write QᵀAQ = D. For a complex normal matrix, use U†AU = D with U unitary. If A = PDP⁻¹, then Aᵏ = PDᵏP⁻¹ for positive integers k.
